# คลังข้อสอบ

ข้อสอบเก่า (PDF) → ล้างอัตโนมัติ → คนตรวจในเว็บ → ใช้ทำข้อสอบ

## ใส่ไฟล์ใหม่
วางไฟล์ตามนี้ (ชื่อโฟลเดอร์ = บล็อก / รุ่น):
```
library/raw/Respiratory/52/MCQ.pdf        ← ข้อสอบ
library/raw/Respiratory/52/MCQ-key.pdf    ← เฉลย (ไฟล์ที่ไฮไลต์คำตอบ)
```
แล้วรัน:
```
python3 library/tools/build_clean.py --all
```
ต้องติดตั้งครั้งแรก: `pip install pymupdf`

## ผลลัพธ์
- `library/clean/*.json` ข้อสอบสะอาดที่เว็บอ่าน (index.json คือสารบัญ)
- `library/images/` รูปประกอบโจทย์และภาพตัดจากต้นฉบับ (ไว้ตรวจเทียบ)
- `library/decisions/<ชื่อ>.json` ผลที่คนตัดสินในแท็บ "ตรวจเฉลย" (ดาวน์โหลดจากเว็บแล้ววางที่นี่ จากนั้นรัน build_clean ซ้ำ)
- `library/evidence/` หลักฐานเฉลยจากข้อความ (ใช้เมื่อยังไม่มี PDF)
- `library/manifest.json` สารบัญไฟล์ต้นฉบับใน Drive

## สถานะของแต่ละข้อ
| สถานะ | ความหมาย | ใช้ทำข้อสอบ |
|---|---|---|
| ✅ ผ่าน | เฉลยอ่านได้ชัดจากไฟล์เฉลย หรือคนยืนยันแล้ว | ใช้ |
| 🔎 กวาดตาดู | ตรงกับไฟล์เฉลยแต่ต้องตีความเล็กน้อย | ไม่ใช้ จนกว่าจะยืนยัน |
| ⚠️ ต้องตรวจ | ไม่มีเฉลย / ไฮไลต์กำกวม / ขัดกัน / โจทย์อ้างรูปแต่ไม่พบรูป | ไม่ใช้ |
| ❌ ใช้ไม่ได้ | ตัวเลือกไม่ครบ หรือไม่มีคำตอบที่ถูก | ไม่ใช้ |

## หลักความปลอดภัย
- เฉลยมาจากไฟล์เฉลย (ไฮไลต์/ข้อความ) เท่านั้น ไม่เดาเอง
- ข้อเดียวกันซ้ำหลายชุดแต่เฉลยไม่ตรงกัน → ติด ⚠️ ทั้งหมด
- ทดสอบตัวอ่าน PDF: `python3 library/tools/selftest.py`
- ไฟล์ใหญ่กว่า 100 MB push ขึ้น GitHub ไม่ได้ ต้องบีบอัดก่อน

## ความเห็นหลายฝั่ง (เฉลยทำกันเองอาจผิด)
ทุกข้อเก็บ "ความเห็น" จากหลายแหล่ง: ไฟล์เฉลย, ข้อซ้ำรุ่นอื่น (เทียบอัตโนมัติเมื่อมีหลายชุดในคลัง), AI และ Lecture (`library/opinions/<ชื่อ>.<แหล่ง>.json`)
ถ้าแหล่งไหนเห็นต่างจากไฟล์เฉลย ข้อนั้นจะเป็น ⚠️ และยังไม่ถูกใช้ทำข้อสอบ จนกว่าคุณจะเลือกคำตอบในแท็บ "ตรวจเฉลย" (คำตัดสินของคุณชนะทุกอย่าง)
ความเห็นของ AI ใช้เตือนเท่านั้น อาจผิดได้
